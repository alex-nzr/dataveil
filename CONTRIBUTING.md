# Вклад в развитие проекта

Любая помощь в развитии проекта приветствуется. Ниже описано, как вы можете внести свой вклад.

## Способы участия

- **Pull Request:** вы можете предложить реализацию новых возможностей или исправить найденные ошибки.
- **Issue:** в случае ошибок вы можете написать тикет с описанием или предложить новые возможности.
- **Конфигурация:** можете обновить `configuration.yaml` при выходе/изменения новых таблиц битрикса.

## Pull Request

Для внесения изменений (PR) необходимо учитывать следующие особенности:

- Проверьте версию **PHP 8.1** и СУБД **MySQL 5.7** и ее аналоги.
  Мы вынуждены поддерживать разные версии битрикса, поэтому это минимальная поддерживаемая версия на данный момент.
- Установите зависимости через `composer install`.
- Для **сборки PHAR** потребуется утилита `humbug/box` (устанавливайте глобально).
- Команда сборки:
  ```bash
  composer build:phar
  ```
- Следите за качеством вашего кода:
  ```
  composer analyse
  ```
- Пишите unit-тесты и следите за корректностью тестов:
  ```bash
  composer test
  ```
- Для локальных тестов используйте `php DataVeil.php` или собранный архив `php dataveil.phar`.

## Оформление тикетов

При описании граничных ситуаций пожалуйста, укажите максимально подробную информацию:

1. **Конфигурация:** Приложите фрагмент `configuration.yaml`, на котором моделируется проблема.
2. **Объем данных:** Укажите размер таблиц и количество записей, на которых воспроизводится ситуация.
